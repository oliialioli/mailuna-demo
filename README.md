# Mailuna · demo

Demo interactiva (prototipo) de Mailuna: análisis de apoyos de líneas eléctricas con inteligencia artificial y LiDAR.

**Abrir la demo:** https://oliialioli.github.io/mailuna-demo/

Es una página estática de un solo archivo (`index.html`) con datos de ejemplo; el acceso viene rellenado y no hay autenticación real ni peticiones de red (solo las tipografías de Google Fonts).
Recomendado: Chrome, Edge, Safari o Firefox recientes con WebGL activado.
